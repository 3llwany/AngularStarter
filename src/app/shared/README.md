# `src/app/shared` — مكونات الواجهة المشتركة والأدوات المساعدة

يحتوي هذا المجلد على مكتبة مكونات نظام التصميم العامة (`src/app/shared/ui/`)، والمكونات العرضية عديمة الحالة، والأنابيب (`Pipes`) والتوجيهات (`Directives`) المشتركة بين الميزات.

## قواعد الحدود المعمارية (تُفرَض عبر Sheriff و ESLint)

- **الاستيراد المسموح**: الحزم الخارجية (بما فيها `primeng/*` داخل `src/app/shared/ui/**` فقط) والملفات الأخرى داخل `src/app/shared/**`.
- **الاستيراد الممنوع**: `src/app/core/**` و `src/app/features/**`.
- يجب أن تخفي مكونات `src/app/shared/ui/**` أنواع PrimeNG بالكامل عن مدخلاتها ومخرجاتها العامة.
