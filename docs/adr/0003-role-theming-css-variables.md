# قرار معماري ADR-0003: تلوين السمات حسب الدور عبر متغيرات CSS ومزامنة PrimeNG

- **الحالة**: مقبول (Accepted)
- **التاريخ**: 2026-11-11
- **السياق**: يمتلك مذاكرتي ستة أدوار (`student`, `parent`, `teacher`, `school`, `partner`, `admin`). نحتاج أن يتغيّر اللون الأساسي للتطبيق في كل من كلاسات Tailwind (`bg-primary-600`, `text-primary-700`, `border-primary-500`) ومكونات PrimeNG المغلّفة في وقت التشغيل دون إعادة تحميل الصفحة، ودون حدوث وميض للون الافتراضي قبل تحميل الصفحة في المتصفح أو SSR.

## القرار

1. **متغيرات CSS على السمة `[data-role]`**: تعريف `--moz-primary-50` إلى `--moz-primary-950` و `--moz-on-primary` و `--moz-on-primary-500` على `:root` / `[data-role="student"]` وبقية الأدوار الستة داخل `src/styles.css`.
2. **مزامنة Tailwind CSS v4 مع PrimeNG**:
   - ربط `--color-primary-50..950` داخل `@theme inline` بـ `var(--moz-primary-50..950)`.
   - تعريف `MozAuraPreset` عبر `@primeuix/themes` `definePreset(Aura, ...)` بحيث يشير إلى نفس متغيرات `--moz-primary-*` مع تعطيل الوضع الداكن (`darkModeSelector: false`) وضبط ترتيب طبقات `@layer`.
3. **لوحة ألوان محايدة للإدارة (`admin`)**: تخصيص لوحة Indigo/Slate عالية الوضوح لشاشات الإدارة كثيفة البيانات.
4. **قاعدة تباين WCAG AA**:
   - درجات `500` لبعض ألوان الأدوار لا تحقق تبايناً يبلغ `4.5:1` مع النص الأبيض (`2.15:1` إلى `4.23:1`).
   - لذلك تعتمد عناصر الواجهة الرئيسية المعبّأة الدرجة `600` (و`700` عند المرور و`800` عند الضغط) مع `#FFFFFF` (`--moz-on-primary`) مما يحقق تبايناً **`>= 4.8:1`** عبر الأدوار الستة جميعها، وتخضع هذه القيم لفحص آلي في `role-palettes.spec.ts`.
5. **الحفظ في الكوكيز ومنع الوميض (FOUC)**: تحفظ `ThemeService` الدور النشط في الكوكي `moz_role` وتحدّث `<html data-role="...">`، بينما يقرأ سكريبت مبكر في `src/index.html` وخادم SSR الكوكي قبل أول رسم للصفحة.

## النتائج والتبعات

- **إيجابيات**: لا حاجة لحسابات JS للّون أثناء التشغيل، انعدام وميض السمة عند التحميل، مصدر حقيقة واحد لـ Tailwind و PrimeNG، وضمان التباين بالاختبارات الآلية.
- **سلبيات**: إضافة دور سابع مستقبلاً تتطلب إضافة كتلة متغيرات `[data-role]` في `src/styles.css` وتعريفها في `ROLE_PALETTES`.
