# سجل مساهمات مكتبة واجهة المستخدم (`ng-ui-components`)

يتتبّع هذا الملف كل مكوّن جديد أو تعديل يتم داخل `src/app/shared/ui/` ليتمكن المشرف من مراجعته ودفعه إلى مستودع `github.com/3llwany/ng-ui-components` يدوياً عبر `git ui-push`.

> **القواعد الإلزامية:**
> - يُمنع تماماً تشغيل أوامر `git ui-push` أو `git ui-pull` أو `git ui-init` بشكل تلقائي.
> - يجب أن تبقى جميع مكونات `src/app/shared/ui/` عامة بنسبة 100% ومستقلة تماماً عن منطق مشروع مذاكرتي أو أدواره.
> - أي تعديل داخل `src/app/shared/ui/foundation/` يجب تمييزه بوضوح أدناه لأنه يؤثر على جميع المشاريع المستهلكة للمكتبة.

## عقد متغيرات الـ CSS المتوقعة (Expected CSS Variables Contract)

يجب على كل مشروع يستهلك مكتبة `ng-ui-components` توفير المتغيرات التالية:
- `--moz-primary-50` حتى `--moz-primary-950` (أو `--primary-50..950`): درجات اللون الأساسي للدور النشط.
- `--primary-contrast`: لون النص عالي التباين فوق الدرجة `500` (بنسبة تباين لا تقل عن `4.5:1` حسب معيار WCAG AA).
- `--primary-gradient`: متغير التدرج اللوني المستخدم في خلفيات الأزرار.
- `--font-sans`: عائلة الخط الأساسية (يتم وراثتها من العنصر `body`).
